## Deliberate adaptations

- Per-project Codex copies, not a native Codex plugin or global symlinks.
- Claude implements and Codex reviews by default; roles and optional models are
  independently configured. Same-provider role pairs still use separate sessions.
- Bash and jq only. Retain stdin transport, Git Bash routing and the Claude-only
  Honcho workaround.
- Explicit asset location (default ./docs) and ticket method (default local).
  Local and GitHub are headless adapters; other stores retain interactive guidance.
- Keep the triage gate, AFK/HITL classification and existing Markdown ticket shape.
  Existing FoS YAML conventions remain supported without mass conversion.
- Adopt to-spec/to-tickets/spec.md without old-name aliases. Add codebase-design
  as the shared reference rather than maintaining duplicated design material.
- Review working changes, not merely committed HEAD. Concrete violations block;
  advisory smells do not. Two repair attempts, then verified recovery and handoff.
- Preserve custom setup files, ignored assets and modified installed skills.
  Relocation is previewed and scoped to workflow assets and their references.
- Full README, metadata, skill and template consistency sweep.

## Deferred

Wizard, research, retro, wayfinder, separate grilling/domain-modeling skills,
native Jira/GitLab headless adapters, release CI replacement, per-ticket worktrees,
automatic provider fallback and automatic publishing/integration are deferred.

Implementation worktrees belong under
.projects/.worktrees/afk-workflow/, as required by the repository's parent guidance.
FreeLogo FoS is a read-only compatibility reference; no live consumer migration is
part of this plugin release.
